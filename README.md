# Space Invasion

**Space Invasion** — это вертикальный 2D скролл-шутер (shmup) в аниме-стилистике с механикой трансформации корабля игрока. Проект разработан с учетом возможности запуска как в виде **Telegram Web App**, так и в качестве нативного **Android APK** (через Capacitor).

## Технологический стек
- **Язык**: TypeScript
- **Сборщик**: Vite
- **Движок**: Phaser.js 3
- **Мобильный порт**: Capacitor
- **CI/CD**: Jenkins + Docker

## Основные особенности MVP
- **Бесконечный скролл**: параллаксный звездный фон, генерируемый процедурно.
- **Движение**: плавное следование (lerp) корабля за пальцем/курсором.
- **Трансформация**: двойной тап или клик ПКМ переключает форму корабля между Fighter и Mecha (меняются паттерны стрельбы и внешний вид).
- **Аналитика**: базовая архитектура (паттерн Singleton) `AnalyticsService` для логгирования игровых событий.
- **Сюжет**: заглушки `StoryManager` для реализации брифингов и текстовых логов в будущем.

## Разработка

Проект использует `npm` для управления зависимостями. 

```bash
npm install
npm run dev     # Локальный сервер разработки на порту 5173
npm run build   # Сборка продуктовой версии (компиляция TS + Vite)
npm run preview # Локальный предпросмотр собранной версии
```

## Развертывание и CI/CD
В репозитории подготовлены:
- `Jenkinsfile` — пайплайн для автоматической сборки.
- `Dockerfile.android` — образ, содержащий Node.js и Android SDK для сборки APK в Jenkins.
- `capacitor.config.ts` — настройки Capacitor для встраивания веб-билда в Android.

При запуске Jenkins пайплайна генерируются два артефакта:
1. `app-release.apk` (Нативное Android приложение).
2. `spaceinvasion-telegram.zip` (Архив для деплоя в Telegram бота).

Для развертывания веб-версии в Telegram-боте, ознакомьтесь с [Инструкцией по интеграции с Telegram Bot](TELEGRAM_BOT_GUIDE.md).
