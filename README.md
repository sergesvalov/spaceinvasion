# 🚀 Space Invasion

**Space Invasion** — это вертикальный 2D скролл-шутер (shmup) в аниме-стилистике с механикой трансформации корабля игрока. Проект разработан с учетом возможности запуска как в виде **Telegram Web App**, так и в качестве нативного **Android APK** (через Capacitor).

---

## 🛠 Технологический стек
- **Язык**: TypeScript
- **Сборщик**: Vite
- **Движок**: Phaser.js 3
- **Мобильный порт**: Capacitor
- **CI/CD**: Jenkins + Docker

---

## ✨ Основные особенности MVP
- **Бесконечный скролл**: Параллаксный звездный фон, генерируемый процедурно.
- **Интуитивное управление**: Плавное следование (lerp) корабля за пальцем (на мобильных устройствах) или курсором (на ПК).
- **Динамическая трансформация**: Двойной тап или клик ПКМ переключает форму корабля между быстрой формой **Fighter** и мощной формой **Mecha** (меняются паттерны стрельбы, урон и внешний вид).
- **Разнообразный Арсенал**: 
  - **Базовое оружие**: Переключение между Plasma, Ion (большой урон, медленное) и Wave (волновое).
  - **Временные бонусы**: Выпадающие из врагов бонусы дают Spread (веерная стрельба) или Homing (самонаведение) на 10 секунд.
  - **Бомбы**: Очищают экран от снарядов и наносят огромный урон врагам.
  - **Дроны-помощники**: Летают рядом с кораблем и автоматически атакуют врагов.
- **Магазин (Гараж)**: Покупка починки за Кредиты, а также Щитов и Дронов за Антиматерию.
- **Игровой цикл**: Система очков, подсчет жизней (HP), генерация врагов, стрельба и взрывы при столкновениях. Интегрирована вибрация (Haptic Feedback) для Telegram WebApp.
- **Аналитика**: Базовая архитектура (паттерн Singleton) `AnalyticsService` для логгирования игровых событий (смерть, переключение форм, начало уровня).
- **Сюжет**: Система `StoryManager` для реализации брифингов и текстовых логов с HTML-оверлеями.

## ⚔️ Принципы работы оружия и борьбы с ботами

### Оружие и Арсенал
В игре реализована глубокая система вооружения, позволяющая адаптироваться к различным боевым ситуациям:
1. **Базовые классы (выбираются в Гараже)**:
   - **Plasma**: Классический скорострельный лазер. Отлично подходит для подавления мелких врагов.
   - **Ion**: Тяжелые фиолетовые снаряды. Стреляет очень медленно, но наносит колоссальный урон (4x). Идеально против Боссов.
   - **Wave**: Зеленые волновые снаряды, летящие по синусоиде. Наносят 1.5x урона и позволяют задевать врагов, уклоняющихся в стороны.
2. **Временные Супер-пушки (подбираются в бою)**:
   - **Spread (Оранжевый бонус)**: Переопределяет ваше оружие на 10 секунд, заставляя корабль стрелять широким веером из 5 снарядов. Отлично расчищает "толпы" ботов.
   - **Homing (Синий бонус)**: На 10 секунд дает самонаводящиеся ракеты, которые автоматически летят в ближайшего врага. Позволяет сосредоточиться на уклонении.
3. **Бомбы**:
   - Крайняя мера при угрозе уничтожения. Нажатие кнопки 💣 BOMB уничтожает *все вражеские снаряды* на экране и наносит колоссальный урон всем противникам, включая боссов.

### Борьба с ботами (Враги и Боссы)
- **Обычные боты**: Летят сверху вниз и ведут огонь одиночными снарядами. В зависимости от текущей фазы уровня, частота их появления (спавн-рейт) увеличивается вплоть до 3-кратного ускорения ближе к концу уровня. Эффективнее всего сбивать их из базового оружия Plasma или использовать дрона-помощника для автоматического отстрела.
- **Боссы (Истребителеноситель)**: Обладают огромным запасом прочности и атакуют в стиле "Bullet Hell" (заградительный огонь). Для борьбы с ними рекомендуется:
  - Использовать **Ion** пушку для максимизации урона в секунду.
  - Трансформироваться в **Mecha** (двойной тап/клик ПКМ), чтобы увеличить базовый урон в 2 раза и получить 2 линии стрельбы.
  - Включать **Щиты** (кнопка SHIELD), чтобы безопасно проходить сквозь стену пуль.
- **Дроны-помощники**: Рекомендуется всегда покупать дрона (5 Антиматерии в гараже). Он автоматически наводится на ботов, что особенно полезно, когда вам нужно маневрировать среди пуль.

## 🌍 Структура Уровней (Прогрессия)

Игра поддерживает систему фаз уровней с динамической сменой декораций и нарастанием сложности:
- **Фаза 1: Город (0-20 сек)** — полет над неоновым городом, стандартный спавн врагов.
- **Фаза 2: Пригороды (20-40 сек)** — плавный кроссфейд текстур фона (fade-in), спавн врагов ускоряется на 20%.
- **Фаза 3: Горы (40-60 сек)** — кроссфейд на текстуру гор, максимальная сложность и плотность врагов.
- **Финал: Битва с Боссом** — спавн обычных врагов останавливается. Сверху спускается огромный **Истребителеноситель**, который атакует плотным заградительным огнем (Bullet Hell) и периодически выпускает из ангаров самолеты-камикадзе. Уничтожение босса ведет к победе на уровне и зачислению бонуса.

## 📂 Структура проекта

- `src/game/` — Исходный код игры на Phaser 3.
  - `scenes/` — Игровые сцены (например, `GameScene`).
  - `entities/` — Игровые сущности (`Player`, `Enemy`, `Projectile` и т.д.).
- `src/services/` — Вспомогательные сервисы (Аналитика, Сюжет).
- `android/` — Сгенерированный нативный проект Android (через Capacitor).
- `Dockerfile.android` / `Dockerfile.web` — Docker-образы для сборки окружения CI/CD.

## 💻 Разработка (Локальный запуск)

Проект использует `npm` для управления зависимостями. 

```bash
# Установка зависимостей
npm install

# Локальный сервер разработки (откроется на порту 5173)
npm run dev

# Сборка продуктовой версии веб-приложения (компиляция TS + Vite)
npm run build

# Локальный предпросмотр собранной версии
npm run preview
```

### Сборка Android-версии локально
Для работы с Android-версией убедитесь, что у вас установлен Android Studio.
```bash
npm run build
npx cap add android   # Если папка android еще не создана
npx cap sync android  # Обновить ассеты после билда
npx cap open android  # Открыть проект в Android Studio
```

## 🏗 Развертывание и CI/CD (Jenkins)

Проект полностью настроен для автоматической сборки через Jenkins. 

В репозитории подготовлены:
- `Jenkinsfile` — Пайплайн для автоматической сборки как веб-версии, так и Android-приложения.
- `Dockerfile.android` — Кастомный образ на базе Debian (Bookworm), содержащий Node.js и Android SDK. *Образ автоматически применяет ARM-патчи (android-arm-build-tools) для сборки на архитектуре ARM64.*
- `capacitor.config.ts` — Настройки Capacitor для встраивания веб-билда в Android.
- `release.keystore` — Ключ для автоматической подписи релизных APK в CI/CD (используются `zipalign` и `apksigner`).

При успешном завершении Jenkins пайплайна генерируются артефакты:
1. `spaceinvasion-pc.zip` (ПК-версия: распакуйте и запустите `PlayGame.bat` для мгновенной игры на Windows).
2. `spaceinvasion-mac.zip` (Mac-версия: распакуйте и запустите `PlayGame.command` для игры на macOS).
3. `spaceinvasion-release.apk` (Готовое, выровненное и подписанное нативное Android приложение).
4. `spaceinvasion-telegram.zip` (Архив для деплоя веб-версии в Telegram бота).

Для развертывания веб-версии в Telegram-боте, ознакомьтесь с [Инструкцией по интеграции с Telegram Bot](TELEGRAM_BOT_GUIDE.md).
