# Запуск игры в Telegram (Web App)

Данная инструкция описывает шаги по запуску собранного проекта `Space Invasion` внутри Telegram-бота в качестве **Telegram Web App**.

## Шаг 1: Получение файлов сборки
После завершения работы Jenkins пайплайна, скачайте артефакт `spaceinvasion-telegram.zip` и распакуйте его. Это обычные статические веб-файлы:
- `index.html`
- Папка `assets/` (стили и скрипты)

## Шаг 2: Размещение файлов на хостинге
Telegram Web App работает как обычный iframe в браузере, поэтому файлы должны быть доступны в интернете по протоколу **HTTPS**.

Вы можете загрузить их на любой статический хостинг. Популярные варианты:
- **GitHub Pages**
- **Vercel** / **Netlify**
- Ваш собственный сервер (например, **Nginx** или **Apache**)

> **Важно:** Убедитесь, что ваш хостинг отдает `index.html` в качестве входной точки и поддерживает `HTTPS`.

## Шаг 3: Настройка бота (через BotFather)
1. Откройте Telegram и найдите официального бота **@BotFather**.
2. Создайте нового бота (команда `/newbot`) или выберите существующего (`/mybots`).
3. Для того чтобы добавить кнопку запуска Web App в меню бота:
   - В меню @BotFather выберите: `Bot Settings` -> `Menu Button` -> `Configure menu button`.
   - Отправьте ссылку на ваш развернутый `index.html` (например, `https://my-space-game.vercel.app`).
   - Укажите текст кнопки (например, `Играть!`).

Также вы можете настроить Web App для запуска по инлайн кнопке из сообщений:
```json
{
  "inline_keyboard": [
    [
      {
        "text": "Запустить Space Invasion",
        "web_app": {
          "url": "https://my-space-game.vercel.app"
        }
      }
    ]
  ]
}
```

## Шаг 4: Интеграция с Telegram API (Будущее)
В текущей MVP-версии игра может работать без явного вызова Telegram API. В будущем мы добавим интеграцию с `window.Telegram.WebApp`, чтобы:
- Получать `user_id` для аналитики (`AnalyticsService.ts`).
- Адаптировать интерфейс под безопасные зоны (safe areas) экрана.
- Взаимодействовать с основным интерфейсом Telegram.

Дополнительная информация о разработке: [Документация Telegram Web Apps](https://core.telegram.org/bots/webapps).
